// THE CAB AS WORLD ACTORS (2026-11-08; docs/REVIEW_2026-11-08_power_loader.md §5 item 1).
// The 2026-10-23 cage and beacon were psprite layers bound to AE_LoaderWorn, and in VR a psprite
// layer is positioned from a CONTROLLER (hw_weapon.cpp:256; RenderHUDModel models.cpp:219-226), so
// the cab rotated about the operator's right wrist. They are AE_LoaderCab and AE_LoaderLamp now:
// +NOINTERACTION actors placed every tic at the pawn by AE_LoaderHandler.PlaceCab (zscript/ae/loader.zs),
// the pattern RSQ_UBQSeries/TacticalRig's helmet and torso proved in the owner's headset.
//
// SCALE. loader_cage.md3 keeps mechloader.md3's coordinates: centimetres, origin = the operator,
// x forward, z up. On the WORLD path a model unit is a map unit, so the block carries the
// cm -> map unit scale: 1 m = vr_vunits_per_meter (34). UNIFORM on purpose: models.cpp
// RenderModel already scales a non-voxel model's height by 1 / pixelstretch at the end of its
// transform ("consider the pixel stretching"), so a model authored true renders true; only the
// actor's POSITION height is in stretched units (PlaceCab() divides the metres by pixelstretch
// there). The ACTOR declares Scale 1.0, because the actor's scale multiplies this one
// (models.cpp:82-84).
// No x mirror: the cage is symmetric, and the arms are not drawn here.
Model AE_LoaderCab
{
	Path "Models\Weapons\mech"
	Model 0 "loader_cage.md3"
	// surfaces in the order tools/carve_loader.py writes them: 0 MechGuard.001 (the frame),
	// 1 MechCover (the 48 x 30 cm roof grate)
	SurfaceSkin 0 0 "loader_upper.png"
	SurfaceSkin 0 1 "loader_grate.png"

	Scale 0.34 0.34 0.34
	Offset 0.0 0.0 0.0

	FrameIndex AELC A 0 0
}

// THE BEACON on the cab's roof. loader_lamp.md3 (one surface, loader_alarm) is authored at
// z 251..267 of the PICKUP model, whose origin is at the feet; the cab's roof grate tops out at
// z 95 and the frame at 102, so the lamp comes down 150 model units (cm) to sit on the frame.
// Offset is in model units, applied before Scale (translate(offset / scale) then scale); the
// THIRD number is vertical. Reusing the skin NAME loader_lamp.jpg keeps the brightmap
// (gldefs.txt:13) for free. It spins by its actor angle (PlaceCab() advances it); its light is
// attached to the actor itself (A_AttachLight on a world actor is the ordinary case).
// -150 WANTS THE OWNER'S EYE; it is one number.
